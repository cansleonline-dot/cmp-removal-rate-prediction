# CMP 제거율 예측 및 CSV 배치 자동화

PHM 2016 CMP 공개 데이터를 활용해 공정 센서 기록으로 평균 제거율을 예측하고, 신규 CSV의 전처리부터 예측 결과 저장까지 연결한 Python 프로젝트입니다.

## 1. 프로젝트 목적

- 압력·슬러리 유량·회전값·소모품 사용량으로 평균 제거율을 예측합니다.
- 단순한 공정 그룹 평균 예측과 Random Forest의 오차를 비교합니다.
- 반복적인 파일 읽기·특징 집계·예측·저장을 배치 프로그램으로 연결합니다.

공개 데이터 기반 분석과 로컬 자동화 시연이며, 실제 CMP 장비 실험이나 생산라인 배포 실적은 아닙니다.

## 2. 분석 흐름

```text
원시 센서 CSV
    ↓
WAFER_ID × STAGE 단위 집계
    ↓
공정값 평균·표준편차 / 소모품 사용량 평균 / 공정 그룹 정보
    ↓
결측치 처리 및 범주형 변수 인코딩
    ↓
Random Forest 제거율 예측
    ↓
검증 데이터 평가 및 결과 CSV 저장
```

### 데이터와 특징

- 데이터: PHM 2016 CMP 데이터
- 예측 대상: 평균 제거율(`AVG_REMOVAL_RATE`)
- 표본 단위: 웨이퍼 ID × 공정 단계(STAGE)
- 입력: 공정값 9개의 평균·표준편차, 소모품 사용량 6개의 평균, STAGE·CHAMBER
- 인코딩 전 입력 특징: 26개
- WAFER_ID는 집계·연결용 키로 사용하며 모델 입력에서 제외했습니다.
- 제거율의 물리 단위는 원 데이터 명세 확인 전까지 표기하지 않습니다.

### 전처리와 모델

공정 단계와 챔버별 분포를 확인하고, 그룹별 IQR 기준으로 이상치 후보 28개를 제외해 학습 표본 1,953개를 구성했습니다. 이 표본 수는 고유 웨이퍼 수가 아닙니다.

수치형 결측치는 중앙값으로 대체하고, STAGE·CHAMBER는 원핫 인코딩했습니다. 전처리와 Random Forest(n_estimators=300, random_state=42)를 하나의 Pipeline으로 구성했습니다.

## 3. 예측 성능

별도 validation 데이터의 **424개 ID × STAGE 표본**에 대한 저장 결과 기준입니다. 기준모델은 학습 데이터의 해당 Stage × Chamber 평균 제거율을 예측값으로 사용하는 방법입니다.

| 모델 | MAE |
|---|---:|
| 공정 그룹 평균 기준모델 | 6.101 |
| Random Forest | 2.435 |

**기준모델 대비 전체 MAE 약 60.1% 감소**

MAE는 실제값과 예측값 차이의 절댓값을 평균한 값으로, 낮을수록 좋습니다. 이 개선율은 예측 오차의 감소이며 실제 제거율 또는 수율 증가를 뜻하지 않습니다.

| Stage / Chamber | 검증 표본 수 | 기준모델 MAE | RF MAE | MAE 감소율 |
|---|---:|---:|---:|---:|
| A / 1 | 67 | 3.176 | 2.204 | 30.6% |
| A / 4 | 185 | 5.536 | 2.244 | 59.5% |
| B / 4 | 172 | 7.848 | 2.732 | 65.2% |

전체 RF의 RMSE는 3.268, R²는 0.987입니다. R²는 정확도 백분율이 아니며, 전체 값에는 공정 그룹 간 제거율 차이도 반영됩니다.

## 4. CSV 배치 자동화

프로젝트 원본에는 다음 기능이 구현되어 있습니다.

- 입력 폴더의 CSV를 읽고 학습 때와 동일한 방식으로 특징 집계
- 저장된 전처리·모델 Pipeline과 입력 열 순서 사용
- ID·Stage·Chamber·예측 제거율을 결과 CSV로 저장
- 폴더 내 파일의 이름·크기·수정시각 변화를 감시
- 10초간 변화가 없으면 처리를 시작하고, 완료 표시와 성공·실패 로그 기록

10초는 파일 안정상태 판단을 위한 대기 기준이며 예측 처리시간이 아닙니다. 수동 예측과 자동화 예측은 저장된 비교 결과에서 부동소수점 오차 수준으로 일치했습니다.

## 5. 가상 공정 조건 비교

Stage A / Chamber 4에서 압력과 슬러리 유량의 Low·Mid·High 조합으로 9개 가상 조건을 구성해 예측값을 비교했습니다.

예측값뿐 아니라 압력·유량 두 변수 공간에서 실제 관측 조건과의 최근접 거리도 확인했습니다. 이는 관측 데이터에서 먼 조합을 구분하기 위한 참고 분석이며, 실제 공정 실험·최적 조건 확정·예측 신뢰도 보장을 의미하지 않습니다.

## 6. 평가의 한계와 개선 방향

- 학습·validation의 ID × Stage 조합 중복은 없지만, WAFER_ID만 비교하면 114개가 겹칩니다. 완전히 새로운 웨이퍼에 대한 성능은 ID 단위 분리 평가가 필요합니다.
- 정답 기반 이상치 후보 제외가 내부 학습·시험 분할 전에 적용되었습니다. 분할 후 학습 데이터로만 기준을 정하는 평가와 비필터 평가를 추가할 필요가 있습니다.
- 평균·표준편차 집계는 원시 데이터의 시간순 정보를 보존하지 않습니다.
- 가상 조건 비교는 모델 예측이며 변수의 인과효과를 입증하지 않습니다.
- 자동화는 로컬 배치 시연 단계로, 운영 환경을 위한 동시 처리 제어·재시도 제한 등은 추가 개선 항목입니다.
