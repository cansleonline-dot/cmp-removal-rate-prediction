# 환경 및 보존 범위

원본 백업의 pyvenv.cfg 및 dist-info 디렉터리에서 확인한 환경입니다. 새 환경에 설치하거나 호환성을 재검증한 목록은 아닙니다.

| 항목 | 기록된 버전 |
|---|---|
| Python | 3.14.6 |
| numpy | 2.5.2 |
| pandas | 3.0.5 |
| scikit-learn | 1.9.0 |
| scipy | 1.18.0 |
| joblib | 1.5.3 |
| matplotlib | 3.11.1 |
| seaborn | 0.13.2 |

predict_cmp.py와 watch_cmp.py는 원본 내용을 보존했습니다. 노트북은 출력·실행 번호·셀 메타데이터만 제거했으며 코드와 셀 순서는 보존했습니다. 중간 오류·미정의 변수·중복 실행이 있어 Run All 재현을 보장하지 않습니다. 원시 데이터와 모델은 이 저장소에 포함하지 않습니다. 결과 PNG 2개와 그룹별 성능 CSV는 원본 파일입니다. CSV의 검증_웨이퍼 열은 고유 웨이퍼 수가 아닌 ID × Stage 표본 수입니다.
